## 1. 과제별 분석

### [과제 1] 롯데칠성음료 | 식품 — AI 페르소나 기반 신제품 시장 검증
- **[공식] 세부 내용**: AI 페르소나를 활용한 신제품 가상시장 소비자 반응 시뮬레이션 / 가상 검증 서비스의 아키텍처 및 운영 프로세스 기획
- **실제 문제** [가설]: 신제품 컨셉 검증(설문·FGI·시음회)에 수주의 시간과 비용이 들어, 출시 전 검증할 수 있는 컨셉 수가 제한된다.
- **실무 사용자** [가설]: 상품기획·브랜드 마케팅팀, 소비자조사 담당
- **기존 방식의 어려움** [가설]: 조사 리드타임, 표본 편향, 컨셉 변형(가격·용량·맛·패키지)마다 재조사가 어려움
- **에이전트가 맡을 작업**: 인구통계·음용 습관 기반 페르소나 생성 → 신제품 컨셉 제시 → 구매의향·가격 수용도·불만 요인 응답 → 세그먼트별 집계 → 개선안 재제안 → 재시뮬레이션 루프
- **데이터**
  - 공개: 통계청 인구·가구 통계, 식품소비행태조사(한국농촌경제연구원), 공개 신제품 정보·리뷰(수집 시 약관 확인 필요)
  - 필요: 과거 출시 제품의 **실제 조사 결과·판매 성과** (시뮬레이션 정확도 검증용 정답) [확인 필요: 대회 제공 여부]
- **실현 가능성**: LLM API만으로 프로토타입은 빠르게 가능 → **구현 난이도 낮음**
- **주요 장애물**
  - LLM 페르소나 응답이 실제 소비자와 얼마나 일치하는지 검증이 어려움 (긍정 편향, 응답 동질화)
  - 유사 상용 서비스·연구가 이미 다수 존재 (예: Synthetic Users, Aaru 등 합성 소비자 서비스, 'silicon sampling' 연구) [현재 상태 확인 필요] → 독창성 주장 어려움
  - 진입 장벽이 낮아 참가자 간 아이디어 중복 가능성이 높음 [가설]

### [과제 2] 롯데웰푸드 | 식품 — K-푸드 수출 유망국가 발굴
- **[공식] 세부 내용**: 국가별 식품시장 성장성, 소비 트렌드, 수출입 통계 다각도 분석 / 글로벌 진출 유망국가 TOP 3 도출 및 타당성·추천 근거 제시
- **실제 문제** [가설]: 진출국 판단 근거(통계·트렌드·규제·경쟁)가 여러 출처에 흩어져 있어 비교·갱신에 시간이 많이 들고, 판단 근거가 문서화되지 않음
- **실무 사용자** [가설]: 해외사업·글로벌 전략팀, 수출 영업
- **기존 방식의 어려움** [가설]: 수작업 자료 조사, 국가×품목 조합이 많음, 비관세장벽(할랄·라벨링·첨가물 규정) 정보가 비정형
- **에이전트가 맡을 작업**: 다중 출처 데이터 수집(도구 호출) → 지표 산출 → 다기준 의사결정(가중 점수) → 민감도 분석 → 규제·리스크 조사 → 근거가 달린 TOP 3 리포트
- **데이터**
  - 공개(풍부): UN Comtrade, 관세청 수출입무역통계, KATI 농식품수출정보, World Bank·IMF 거시지표, Google Trends, KOTRA 해외시장뉴스
  - 필요: 롯데웰푸드 품목별 수출 실적·현지 파트너 정보 [확인 필요]
- **실현 가능성**: 공개 데이터로 거의 완전 재현 가능 → **높음**
- **주요 장애물**
  - "정답"이 없어 검증이 어려움 → 과거 시점 데이터로 이후 실제 수출 성장국을 맞히는 **백테스트**로 보완 가능
  - "데이터 대시보드 + LLM 보고서"로 흐르면 흔한 결과물이 될 위험

### [과제 3] 롯데홈쇼핑 | 유통 — 프로모션 시뮬레이터
- **[공식] 세부 내용**: 카드 할인, 사은품 등 조건별 매출 및 고객 반응 시뮬레이션 모델 설계 / 프로모션 유형 및 조합별 성과 비교 및 최적안 도출 로직 기획
- **실제 문제** [가설]: 프로모션 조합(카드 할인·무이자 할부·사은품·적립금)이 많고, 효과가 사후에만 측정되며, 매출 증가가 마진 손실을 정당화하는지 불명확
- **실무 사용자** [가설]: MD, 방송 편성·프로모션 기획, 마케팅
- **기존 방식의 어려움** [가설]: 경험 기반 결정, 프로모션 효과와 상품·시간대·쇼호스트 효과의 분리가 어려움
- **에이전트가 맡을 작업**: 조건 입력(자연어) → 수요·반응 모델 호출 → 조합별 매출·마진 시뮬레이션 → 제약(예산·마진 하한) 하 최적안 탐색 → 근거·리스크 설명
- **데이터**
  - 공개 대체: Dunnhumby "The Complete Journey"(쿠폰·캠페인 포함), M5(가격·이벤트) 등 리테일 데이터 — 단, 홈쇼핑 특성(방송 시간대, 할부, 사은품)은 반영 안 됨
  - 필요: 방송별 매출·주문·프로모션 이력 (**핵심, 내부 데이터 의존도 높음**) [확인 필요: 대회 제공 여부]
- **실현 가능성**: 모델링은 데이터사이언스 역량과 잘 맞음. 데이터가 없으면 시뮬레이터 신뢰도 주장이 약함 → **중간**
- **주요 장애물**: 프로모션이 무작위로 배정되지 않아 인과 효과 추정이 어려움(교란 요인), 제공 데이터 형태에 따라 설계가 크게 바뀜

### [과제 4] 롯데케미칼 | 화학 — 첨단소재 수요예측 AI 기획
- **[공식] 세부 내용**: ABS, PC, 컴파운드 등 최종 고객사(End Customer) 수요예측 체계 설계 / AI 기반 정밀 수요예측(FCST) 프레임워크 및 모델 기획
- **실제 문제** [가설]: B2B 소재는 최종 수요(가전·자동차·IT 기기)가 중간 고객사 주문으로 늦게·증폭되어 전달됨(채찍 효과) → 직접 주문 이력만으로는 예측이 불안정
- **실무 사용자** [가설]: 영업·수요계획(S&OP), 생산계획, 원료 구매
- **기존 방식의 어려움** [가설]: 영업 담당자 감에 의존한 FCST, 전방 산업 지표·뉴스 반영이 수작업
- **에이전트가 맡을 작업**: 전방 산업 선행지표 수집 → 시계열 예측 모델 실행 → 뉴스·이벤트(신차 출시, 가전 수요 변화, 원료가 급등)를 조정 요인으로 반영 → 예측 근거 설명 → 계획자의 질의·보정 대응
- **데이터**
  - 공개: HS코드별 수출입 통계(ABS·PC 해당 코드 — 정확한 코드 [확인 필요]), 자동차 생산(한국자동차산업협회), 산업활동동향, 경기선행지수, 원료 가격 지표(일부 유료)
  - 필요: 고객사별 판매 실적 (**핵심 내부 데이터**) [확인 필요]
  - 공개 대체 전략: 수출입 통계를 "대리 타깃"으로 두면 내부 데이터 없이도 백테스트 가능 [가설]
- **실현 가능성**: 예측 모델 자체는 CPU로 충분 → **중간~높음**. 도메인 이해가 필요
- **주요 장애물**: 소재 산업 도메인 지식, 공개 데이터의 월 단위 해상도, "LLM이 왜 필요한가"에 대한 답이 약하면 단순 시계열 프로젝트로 보일 위험

### [과제 5] 롯데호텔 | 호텔 — 고객 데이터 통합 및 맞춤 추천
- **[공식] 세부 내용**: 브랜드 및 지점별로 분산된 고객 행동·투숙 데이터 통합 체계 설계 / 통합 프로파일링 기반 개인화 객실 및 패키지 맞춤 추천 알고리즘 기획
- **실제 문제** [가설]: 브랜드·지점·채널(직접 예약, OTA, 멤버십)별로 고객 기록이 분리되어 동일 고객 식별과 개인화가 어려움
- **실무 사용자** [가설]: CRM·멤버십 마케팅, 예약·프론트, 레비뉴 매니지먼트
- **기존 방식의 어려움** [가설]: 이름·연락처 표기 차이로 고객 매칭 실패, 세그먼트 단위의 일괄 마케팅
- **에이전트가 맡을 작업**: 이기종 데이터 스키마 매핑 → 동일 고객 식별(엔티티 해석) → 통합 프로필 생성 → 추천 + 추천 사유 설명 → 개인정보 마스킹
- **데이터**
  - 공개 대체: Kaggle Hotel Booking Demand(포르투갈 호텔 2곳 예약 데이터), 공개 호텔 리뷰 데이터, 합성 고객 데이터
  - 필요: 실제 멤버십·투숙 이력 — **개인정보라 외부 사용 가능성 낮음** [확인 필요]
- **실현 가능성**: 추천시스템 경험과 잘 맞음. 다만 합성 데이터만으로는 성능 주장이 약함 → **중간**
- **주요 장애물**: 개인정보보호법(가명처리 요건), 추천 정답 데이터 부재, "통합 체계 설계"는 데이터 엔지니어링 비중이 커서 AI 에이전트 시연이 약해질 위험

### [과제 6] 롯데이노베이트 | 인프라 — SW 공급망 스캐닝 에이전트 기획
- **[공식] 세부 내용**: SBOM 생성 및 취약점 스캔 결과를 영향도·우선순위로 연결하는 아키텍처 설계 / AI 에이전트 기반의 자동 조치안 도출 및 보안 개선 워크플로우 기획
- **용어**: SBOM(Software Bill of Materials) = 소프트웨어에 들어간 오픈소스 부품 목록. 취약점 스캔 = 그 부품 중 알려진 보안 결함(CVE)이 있는 것을 찾는 작업
- **실제 문제** [가설]: 스캔 결과가 수백~수천 건 쏟아지지만 실제 위험한 것은 일부 → 경보 피로, 조치 우선순위·방법 결정이 병목
- **실무 사용자** [가설]: 보안(DevSecOps) 담당, 개발팀, 고객사 SI 프로젝트 PM
- **기존 방식의 어려움** [가설]: CVSS 점수 위주 정렬, 실제 코드에서 취약 함수를 쓰는지 수동 확인, 버전 업그레이드 시 호환성 깨짐 우려
- **에이전트가 맡을 작업**: SBOM 생성 → 스캔 → 위협 정보(EPSS 악용 확률, CISA KEV 실제 악용 목록) 결합 → 코드 내 실제 사용 여부(도달 가능성) 분석 → 업그레이드 경로·호환성 영향 분석 → 조치안·패치 생성 → 테스트 실행으로 검증
- **데이터**
  - 공개(매우 풍부): 오픈소스 프로젝트 자체, Syft·Trivy·Grype(무료 도구), OSV·NVD·GitHub Advisory, EPSS, CISA KEV
  - 필요: 롯데이노베이트 자산 중요도·고객사 환경 정보 [확인 필요] — 없어도 핵심 기능 재현 가능
- **실현 가능성**: 내부 데이터 없이 완전 재현 가능 → **높음**. 보안 도메인 학습 필요
- **주요 장애물**: 상용 경쟁 제품이 많음(예: Snyk, Dependabot, GitHub 자동 수정 기능, 도달 가능성 분석 전문 업체) → 차별화 지점 설계가 핵심. 사용자의 기존 경험과 거리가 있음

### [과제 7] 한국후지필름 | 인프라 — 설문 기반 매출 확대 제안 AI 에이전트 기획
- **[공식] 세부 내용**: 누적된 설문·컨설팅 자료 기반 정기 설문 자동 생성 및 데이터 취합 파이프라인 설계 / 응답 분석 결과에 기반한 B2B/B2C 맞춤형 매출 확대 제안 및 액션플랜 설계
- **실제 문제** [가설]: 설문을 매번 수작업으로 만들고, 결과가 보고서로 끝나 영업 액션으로 이어지지 않음
- **실무 사용자** [가설]: 영업·마케팅, 고객 컨설팅 담당. **한국후지필름의 구체적 사업 범위(B2B 고객군 등)는 [확인 필요]**
- **기존 방식의 어려움** [가설]: 문항 중복·비일관성, 개방형 응답 분석 수작업, 고객별 맞춤 제안 부족
- **에이전트가 맡을 작업**: 과거 자료 기반 문항 생성(이전 응답 기반 적응형) → 배포·수집(폼 API) → 개방형 응답 코딩 → 고객 세그먼트별 기회 탐지 → 맞춤 제안·액션플랜
- **데이터**
  - 공개 대체: 공개 고객 설문 데이터셋, 합성 응답
  - 필요: 누적 설문·컨설팅 자료, 고객별 매출 (**핵심 내부 데이터**) [확인 필요]
- **실현 가능성**: 파이프라인 구현은 쉬움 → **높음**. 그러나 "설문 → 매출"의 효과 입증이 어려움
- **주요 장애물**: 자동 설문 생성·요약 중심이 되면 "흔한 방식"(요구사항 2)에 해당할 위험, 매출 기여 검증 수단 부족

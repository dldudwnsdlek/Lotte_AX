## A. 웰푸드 — 검증형 수출 유망국 추천

| 질문 | 심사위원의 공격 | 답변 / 평가 |
|---|---|---|
| ① 에이전트 필요? | "국가 순위는 1년에 몇 번 내리는 결정이다. 왜 에이전트인가?" | **약함.** 의사결정 빈도가 낮아 대화형 에이전트의 가치가 제한적 |
| ② Python으로 충분? | "순위 모델 + 보고서 템플릿이면 끝나지 않나?" | **대부분 맞음.** LLM이 하는 일이 문장 작성·조건 해석에 그침 |
| ③ 실제 데이터 | | **강함.** 공개 무역·거시 데이터로 완전 재현 |
| ④ 어려워 보이기만? | | 아님. 다만 기술 난도가 높지 않아 "AI 기술 활용 역량"을 보여주기에 약함 |
| ⑤ 예외 상황 | HS 코드에 딱 맞지 않는 신제품, 결측 국가, 범위 밖 질문 | 품목 매핑 확인 단계, 결측 표시, 범위 밖 질문 거절 규칙으로 대응 가능 |
| ⑥ 실제 활용 | "진출 결정은 유통 파트너·규제·현지 생산 등 데이터 밖 요인이 좌우한다" | 맞음. 이 도구는 **1차 후보 압축용**이라는 위치를 분명히 해야 함 |
| ⑦ 더 단순한 해결책 | "백테스트로 가중치를 정한 엑셀 점수표 + 분석가" | **사실상 같은 효과를 냄** |

**치명적 문제**: ①②⑦이 동시에 약하다 → "좋은 데이터 분석"이지만 "AI 에이전트"로서는 약하다.

**개선안 — "가설 검증형 시장 분석 에이전트"로 재설계**
- 고정된 순위 모델 대신, 담당자의 자연어 가설("한류 관심이 높은 나라에서 빼빼로 수입이 빨리 는다", "인도 공장 인접국이 유리하다")을 에이전트가 **분석 계획 → 데이터 조회 → 코드 실행 → 백테스트 → 통계적 판정**까지 수행하고, 검증을 통과한 가설만 순위 모델의 피처로 채택
- 장점: 다단계 계획·도구 사용·자가 검증이 필수가 되어 에이전트 필연성이 올라감
- 새 위험: LLM이 생성한 분석 코드의 오류, 다중 검정(여러 가설을 시험하다 우연히 맞는 것을 고르는 문제) → 검증 절차(사전 고정된 평가 시점, 보정) 필요. **구현 난도도 함께 오름**

**판정: 개선 후 유지(순위 하락)** — 데이터 안정성은 최고지만 에이전트 서사가 약함

## B. 케미칼 — 이벤트 인지형 수요예측

| 질문 | 심사위원의 공격 | 답변 / 평가 |
|---|---|---|
| ① 에이전트 필요? | | **강함.** 비정형 뉴스 → 구조화 이벤트, 이탈 원인 조사(여러 도구를 단계적으로 사용)는 LLM·에이전트가 자연스러움 |
| ② Python으로 충분? | "키워드 개수나 감성 점수만 세도 되지 않나?" | **반드시 비교해야 함.** 베이스라인에 "키워드 빈도 피처"를 추가하고, LLM 구조화가 이것보다 나을 때만 LLM 필요성 주장 |
| ③ 실제 데이터 | "한국 전체 ABS 수출량은 롯데케미칼 판매가 아니다" | 맞음. 국내 여러 생산자의 합계라 **대리 지표일 뿐**임을 명시하고 타깃 교체 가능한 구조로 설계. 뉴스는 GDELT로 2017년 이후 확보 가능성 확인 |
| ④ 어려워 보이기만? | "예측 + 추출 + 보정 + 원인 조사, 혼자 다 되나?" | **위험.** 범위가 넓음 → 원인 조사(4-D)는 시연 수준으로 축소 |
| ⑤ 예외 상황 | 뉴스 없는 달, 상충하는 기사, 루머, 같은 사건 중복 보도, LLM 환각 | 근거 문장 원문 대조, 사건 단위 묶음, 신뢰도 낮은 이벤트 가중치 축소. 뉴스가 없으면 기본 예측 그대로 사용 |
| ⑥ 실제 활용 | | 월간 수요계획 회의(S&OP)에 그대로 들어갈 수 있는 형태. 근거 표시로 담당자 신뢰 확보 가능 |
| ⑦ 더 단순한 해결책 | "담당자가 뉴스를 읽고 손으로 조정하면 된다" | 실제 현업 관행일 가능성이 높음 [가설]. 사람 조정과 직접 비교는 불가 → **"조정 근거의 기록·일관성·속도"**를 가치로 제시 |

**심각한 위험: 효과가 안 나올 수 있다(null result)**
- 월간 데이터 약 100개 시점, 노이즈가 크고 큰 이벤트가 드묾 → 보정 효과가 통계적으로 유의하지 않을 확률이 상당함
- 대처: ① 이벤트 기간만 분리해 평가 ② 국가 패널로 표본 확대 ③ 결과가 나빠도 "LLM 사전지식 누출을 통제한 정직한 평가"를 방법론적 강점으로 제시 — 다만 심사 기준의 "결과 정확성"에는 불리

**범위 축소안**: ABS·PC × 주요 수출국 3~5개, 2017~2024년, 이벤트 유형 6종, 원인 조사는 과거 사례 2~3건 재현

**판정: 개선 후 유지** — AI 필연성·검증 설계는 5개 중 최고. 준비 부담과 효과 불확실성이 최대 약점

## D. 칠성 — 신뢰도 보정 페르소나 패널

| 질문 | 심사위원의 공격 | 답변 / 평가 |
|---|---|---|
| ① 에이전트 필요? | | LLM이 응답자 역할을 하므로 필수. 조사 설계 → 실행 → 신뢰도 측정 → 표본 배정 추천의 다단계 흐름도 있음. 다만 보정 자체는 통계 → **에이전트성은 중간** |
| ② Python으로 충분? | | 보정·배정은 Python, 응답 생성은 LLM. 역할 분담이 명확해 오히려 설명하기 좋음 |
| ③ 실제 데이터 | | **이번 단계에서 개선.** 식품소비행태조사 원자료 2021~2025를 공식 사이트에서 바로 내려받을 수 있음. 단, **음료 관련 문항의 양·형태는 [확인 필요]** |
| ④ 어려워 보이기만? | | 아님. 혼합 추정·최적 표본 배정은 실질적인 통계 문제 |
| ⑤ 예외 상황 | **"일반 식품 소비 문항에서 잰 신뢰도가 신제품 컨셉 평가에도 통하나?"** | **핵심 타당성 문제.** 문항 유형 간 전이를 홀드아웃으로 측정해 한계를 수치로 보여줘야 함. 전이가 안 되면 "어떤 유형의 질문에만 AI를 쓰라"는 규칙으로 축소 |
| ⑥ 실제 활용 | | **강함.** 그룹사(웰푸드)가 이미 AI 소비자 조사를 운영 중이라 [보도] 칠성 도입 시 현행 방식(고정 비중)을 개선하는 구도. "같은 예산 대비 오차 감소" 또는 "조사 비용 절감"으로 수치화 가능 |
| ⑦ 더 단순한 해결책 | "온라인 패널로 300명 실제 조사를 며칠 만에 하면 된다" | 일리 있음. AI의 가치는 **반복 조사(컨셉 수정마다)**와 **실제 조사 표본의 효율적 배분**에 있음 |

**추가 위험**
- 실험 결과 "AI 응답을 섞어도 오차가 거의 안 줄어든다"가 나올 수 있음 → 그 경우에도 "어디에 쓰면 안 되는지 알려주는 운영 장치"로 가치가 있으나 임팩트 서사는 약해짐
- 공식 과제의 "가상시장 소비자 반응 **시뮬레이션**" 자체도 충실히 보여줘야 함 → 신뢰도 계층만 강조하면 시뮬레이션 부분이 빈약해 보일 위험

**판정: 개선 후 유지(순위 상승)** — 데이터 위험이 줄었고, 비즈니스 서사가 5개 중 가장 선명. 남은 확인: 음료 문항

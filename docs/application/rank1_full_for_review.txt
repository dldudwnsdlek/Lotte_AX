[항목 1] 과제 정의 및 해결 방안
==================================================
■ 서비스명: 신뢰도 보정 AI 소비자 패널

1. 문제 정의
- 신제품 컨셉 검증은 설문·FGI·시음회에 수 주의 시간과 비용이 들어, 출시 전 검증할 수 있는 컨셉 수와 반복 횟수가 제한됩니다. 칠성의 글로벌 매출 비중이 40%대로 커지면서(언론 보도) 국가·세그먼트별 검증 수요는 더 늘고 있습니다.
- LLM으로 만든 AI 소비자는 빠르고 저렴하지만, 핵심 문제는 "AI 응답을 언제 믿을 수 있는가"입니다. AI 응답이 실제 소비자와 맞는 정도는 세그먼트(성별·연령·음용 습관)와 문항 유형(선호·빈도·가격·이유)에 따라 다릅니다. 그런데 일반적인 활용 방식은 AI 응답을 일괄 신뢰하거나 실제 응답과 고정 비중으로 섞습니다. 언론 보도에 따르면 그룹 내에서도 AI 소비자와 실제 소비자의 응답을 같은 비중으로 반영해 컨셉 조사에 활용하는 사례가 있습니다.
- 그 결과 (1) AI가 틀리는 구간에서 잘못된 의사결정이 나올 위험과 (2) AI가 잘 맞는 구간에도 실제 조사 비용을 그대로 쓰는 비효율이 동시에 존재합니다.

2. 해결 방안
AI 소비자 시뮬레이션에 '신뢰도 계층'을 결합한 시장 검증 에이전트입니다.
① 가상시장 시뮬레이션: 인구·음용 습관 통계 분포에 맞춘 AI 소비자 패널을 생성해, 신제품 컨셉(맛·당류·용량·가격·패키지)에 대한 구매의향, 가격 수용도, 선택·거부 이유를 수집합니다.
② 신뢰도 지도: 실제 응답이 있는 기준 조사를 AI 패널로 똑같이 재현해, 세그먼트×문항 유형별 AI-실제 응답 일치도를 측정합니다. 결과는 "신뢰 / 주의 / AI 사용 금지" 등급 지도로 제공합니다.
③ 하이브리드 조사 설계: 신뢰도가 낮은 세그먼트에 실제 조사 표본을 집중 배정하고, AI와 실제 응답을 신뢰도에 따라 다른 비중으로 결합해 최종 추정치와 불확실성 구간을 제시합니다.
④ 운영 프로세스: 실제 조사 결과가 들어올 때마다 신뢰도 지도를 갱신하는 순환 구조로 운영합니다. 사용할수록 AI 패널을 써도 되는 범위가 데이터로 확장·축소됩니다.

[사용 시나리오] 브랜드 담당자가 "저당 탄산 신제품 컨셉 3종"을 입력 → 에이전트가 AI 패널 조사 실행 → 컨셉별 선호·가격 수용도와 세그먼트별 신뢰도 표시 → "실제 조사 300명 중 220명을 신뢰도가 낮은 50대 이상에 배정" 같은 조사 설계안 제시 → 실제 결과 회수 후 결합 추정과 최종 판단 리포트 제공

[단계적 도입안] 1단계 국내 탄산·제로 음료 컨셉 조사 → 2단계 주류(하이볼·무알콜 등)로 확장 → 3단계 해외 법인·수출국 소비자로 확장. 단계마다 실제 조사 결과로 신뢰도 지도를 먼저 쌓은 뒤 AI 비중을 늘리므로, 검증되지 않은 시장에서 AI를 과신하지 않습니다.

3. 기대 효과 (본선에서 정량 검증할 목표)
- 정확도: 같은 실제 조사 표본 수에서 '실제 응답만 사용', '고정 비중 혼합' 대비 추정 오차 감소
- 비용·시간: 같은 정확도에 필요한 실제 조사 표본 수 절감 → 조사 비용 절감액으로 환산
- 의사결정 품질: 컨셉을 수정할 때마다 수 분 내 반복 검증 가능, AI 결과를 써서는 안 되는 구간을 사전 경고
- 확산성: 신뢰도 계층은 특정 제품에 종속되지 않아 주류·해외 시장 조사와 그룹 내 다른 식품 계열사의 AI 소비자 조사에도 적용 가능

4. 차별성
- 기존 AI 페르소나 서비스와 일반적 접근은 "AI 소비자에게 묻고 결과를 보고"하는 데서 끝납니다. 본 안은 결과의 신뢰도를 세그먼트·문항 단위로 측정하고, 그 측정값으로 실제 조사 예산 배분까지 결정합니다.
- AI를 실제 조사의 대체재가 아니라 '하이브리드' 구성 요소로 설계해, 현업이 결과를 믿고 쓸 근거(신뢰도 등급·불확실성 구간)를 함께 제공합니다.
- 성과를 인상 평가가 아닌 '추정 오차'와 '조사 비용'이라는 측정 가능한 지표로 제시합니다.
- 공개 데이터만으로 사전 검증이 가능합니다. 한국농촌경제연구원 식품소비행태조사에는 가당 탄산과 제로 탄산을 구분한 선호 음료 문항, 제로 음료 섭취 빈도·이유 문항이 있어, 칠성의 주력 카테고리에서 AI 응답의 신뢰도를 바로 측정할 수 있습니다.

5. 사용자와 업무 적용 지점
- 1차 사용자: 상품기획·브랜드 마케팅 담당자(컨셉 선별·수정), 소비자조사 담당자(조사 설계·예산 배분)
- 적용 지점: 아이디어 단계의 다수 컨셉을 AI 패널로 빠르게 걸러낸 뒤, 최종 후보만 하이브리드 조사로 정밀 검증합니다. 기존 조사 프로세스를 대체하지 않고 앞단과 예산 배분 단계에 결합되므로 도입 부담이 작습니다.

[항목 2] AI 에이전트 구축 방안
==================================================
1. AI 모델 설계
(1) AI 소비자 생성: 공개 통계(인구·가구 통계, 식품소비행태조사)의 분포를 따라 층화 샘플링한 속성(성별·연령·가구·지역·음용 습관·제로 음료 섭취 빈도 등)을 LLM 프롬프트에 주입합니다. 응답은 JSON 스키마로 강제(구조화 출력)해 집계 오류를 막습니다.
(2) 신뢰도 측정: 세그먼트×문항 유형별로 AI 응답 분포와 실제 응답 분포의 거리(Jensen-Shannon 거리), 평균 차이, 순위 상관을 계산하고, 부트스트랩으로 신뢰구간을 붙여 신뢰도 등급을 산출합니다.
(3) 보정·결합: 사후 가중(raking)과 분포 재보정으로 AI 응답의 체계적 편향을 줄이고, 세그먼트별 편향과 분산을 반영한 가중 결합으로 최종 추정치를 계산합니다. 편향이 큰 구간은 AI 비중이 0에 가까워집니다.
(4) 표본 배정 최적화: 세그먼트별 불확실성에 비례해 실제 조사 표본을 배분(네이만 배분 응용)해, 주어진 예산에서 전체 추정 오차를 최소화합니다.

2. 활용 데이터
- 예선·사전 검증: 한국농촌경제연구원 식품소비행태조사 원자료(공개). 성인 가구원 조사표의 선호 음료 1~3순위(가당·제로 탄산 구분), 제로 음료 섭취 빈도, 섭취·비섭취 이유, 음주 빈도·선호 주종 문항을 기준 데이터로 씁니다. 매년 반복되는 조사라 '전년도로 보정 → 다음 연도 실제 응답으로 검증'하는 시간 분리 검증이 가능합니다.
- 본선: 현장 데이터(예: 과거 컨셉 조사 결과, 소비자 조사, 판매 데이터)를 보정 기준으로 연결합니다. 입력 스키마를 표준화해, 데이터 형식이 달라도 문항·세그먼트 매핑만 바꾸면 적용되도록 합니다.
- 컨셉 정보: 담당자가 입력하는 제품 속성(맛·당류·용량·가격·패키지·타깃)

3. AI 에이전트 개발 방식
- 구조: LLM(OpenAI API)이 계획 수립과 도구 호출을 담당하고, 계산은 검증된 Python 도구가 수행하는 함수 호출 기반 워크플로입니다. 도구는 패널 생성기, 설문 실행기, 신뢰도 계산기, 보정·결합기, 표본 배정기, 리포트 생성기로 구성합니다.
- 흐름: 요청 해석(컨셉·타깃·예산) → 문항 설계 → AI 패널 조사 실행 → 신뢰도 지도 조회·갱신 → 결합 추정과 불확실성 계산 → 실제 조사 설계안 제시 → 리포트 작성 및 후속 질문(what-if) 응답
- 화면: Streamlit으로 컨셉 비교, 세그먼트별 신뢰도 히트맵, 표본 배정안을 제공합니다.
- 1박 2일 개발 전략: 데이터 연결부를 표준 스키마로 분리해 현장 데이터 적용 시간을 최소화하고, 핵심 3기능(신뢰도 지도·결합 추정·표본 배정)을 우선 완성합니다.

4. 신뢰성·안정성 확보 방안
- 정량 검증: 전체 실제 응답을 참값으로 두고 실제 조사 예산을 일부로 제한한 상황에서 ⓐ실제 응답만 ⓑ고정 비중 혼합 ⓒ신뢰도 기반 혼합의 오차를 반복 표본추출로 비교합니다. 또 문항 유형별 홀드아웃으로 신뢰도가 다른 유형의 문항에도 통하는지(전이 가능성) 측정하고, 한계를 결과에 명시합니다.
- 환각·계산 오류 방지: LLM은 응답 생성과 해석만 맡고 모든 수치는 Python 도구가 계산합니다. 리포트에 적힌 수치는 계산 결과와 자동 대조합니다.
- 응답 품질 관리: 모든 AI 소비자가 비슷하게 답하는 응답 동질화를 분포 다양성 지표로 감시하고, 프롬프트 변형과 복수 모델 비교로 완화합니다. 같은 조건을 반복 실행했을 때의 결과 변동폭도 함께 보고합니다.
- 안전장치: 신뢰도가 낮은 구간의 결과는 자동으로 '참고 불가'로 표시하고 실제 조사를 권고합니다. 개인 단위 실제 데이터는 비식별 처리 후 사용합니다.
- 비용·운영 안정성: 배치 호출과 캐시로 API 비용을 통제하고, API 장애가 나도 캐시된 패널 결과로 시연할 수 있도록 설계합니다.

5. 성능 평가 지표
- 신뢰도 측정: 세그먼트별 Jensen-Shannon 거리, 컨셉 선호 순위 상관
- 결합 추정: 참값 대비 평균 절대 오차(MAE)와 불확실성 구간의 실제 포함률
- 비용 효과: 같은 오차를 달성하는 데 필요한 실제 표본 수(비교 방식 대비 절감률)
- 안정성: 반복 실행 간 결과 변동폭, 응답 형식 오류율, 응답 소요 시간

6. 본선 시연 구성
컨셉 입력 → AI 패널 조사 실행 → 세그먼트별 신뢰도 히트맵 → 실제 조사 표본 배정안 → 현장 데이터 기반 백테스트로 '실제만 / 고정 혼합 / 신뢰도 기반 혼합'의 오차 비교 그래프를 한 화면에서 보여줍니다.

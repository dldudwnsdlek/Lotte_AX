1. AI 모델 설계
(1) AI 소비자 생성: 공개 통계(인구·가구 통계, 식품소비행태조사)의 분포를 따라 층화 샘플링한 속성(성별·연령·가구·지역·음용 습관·제로 음료 섭취 빈도 등)을 LLM 프롬프트에 주입합니다. 응답은 JSON 스키마로 강제(구조화 출력)해 집계 오류를 막습니다.
(2) 신뢰도 측정: 세그먼트×문항 유형별로 AI 응답 분포와 실제 응답 분포의 거리(Jensen-Shannon 거리), 평균 차이, 순위 상관을 계산하고, 부트스트랩으로 신뢰구간을 붙여 신뢰도 등급을 산출합니다.
(3) 보정·결합: 사후 가중(raking)과 분포 재보정으로 AI 응답의 체계적 편향을 줄이고, 세그먼트별 편향과 분산을 반영한 가중 결합으로 최종 추정치를 계산합니다. 편향이 큰 구간은 AI 비중이 0에 가까워집니다.
(4) 표본 배정 최적화: 세그먼트별 불확실성에 비례해 실제 조사 표본을 배분(네이만 배분 응용)해, 주어진 예산에서 전체 추정 오차를 최소화합니다.

2. 활용 데이터
- 예선·사전 검증: 한국농촌경제연구원 식품소비행태조사 원자료(공개). 성인 가구원 조사표의 선호 음료 1~3순위(가당·제로 탄산 구분), 제로 음료 섭취 빈도, 섭취·비섭취 이유, 음주 빈도·선호 주종 문항을 기준 데이터로 씁니다. 매년 반복되는 조사라 '전년도로 보정 → 다음 연도 실제 응답으로 검증'하는 시간 분리 검증이 가능합니다.
- 본선: 현장 데이터(예: 과거 컨셉 조사 결과, 소비자 조사, 판매 데이터)를 보정 기준으로 연결합니다. 입력 스키마를 표준화해, 데이터 형식이 달라도 문항·세그먼트 매핑만 바꾸면 적용되도록 합니다.
- 컨셉 정보: 담당자가 입력하는 제품 속성(맛·당류·용량·가격·패키지·타깃)

3. AI 에이전트 개발 방식
- 구조: LLM(OpenAI API)이 계획 수립과 도구 호출을 담당하고, 계산은 검증된 Python 도구가 수행하는 함수 호출 기반 워크플로입니다. 도구는 패널 생성기, 설문 실행기, 신뢰도 계산기, 보정·결합기, 표본 배정기, 리포트 생성기로 구성합니다.
- 흐름: 요청 해석(컨셉·타깃·예산) → 문항 설계 → AI 패널 조사 실행 → 신뢰도 지도 조회·갱신 → 결합 추정과 불확실성 계산 → 실제 조사 설계안 제시 → 리포트 작성 및 후속 질문(what-if) 응답
- 화면: Streamlit으로 컨셉 비교, 세그먼트별 신뢰도 히트맵, 표본 배정안을 제공합니다.
- 1박 2일 개발 전략: 데이터 연결부를 표준 스키마로 분리해 현장 데이터 적용 시간을 최소화하고, 핵심 3기능(신뢰도 지도·결합 추정·표본 배정)을 우선 완성합니다.

4. 신뢰성·안정성 확보 방안
- 정량 검증: 전체 실제 응답을 참값으로 두고 실제 조사 예산을 일부로 제한한 상황에서 ⓐ실제 응답만 ⓑ고정 비중 혼합 ⓒ신뢰도 기반 혼합의 오차를 반복 표본추출로 비교합니다. 또 문항 유형별 홀드아웃으로 신뢰도가 다른 유형의 문항에도 통하는지(전이 가능성) 측정하고, 한계를 결과에 명시합니다.
- 환각·계산 오류 방지: LLM은 응답 생성과 해석만 맡고 모든 수치는 Python 도구가 계산합니다. 리포트에 적힌 수치는 계산 결과와 자동 대조합니다.
- 응답 품질 관리: 모든 AI 소비자가 비슷하게 답하는 응답 동질화를 분포 다양성 지표로 감시하고, 프롬프트 변형과 복수 모델 비교로 완화합니다. 같은 조건을 반복 실행했을 때의 결과 변동폭도 함께 보고합니다.
- 안전장치: 신뢰도가 낮은 구간의 결과는 자동으로 '참고 불가'로 표시하고 실제 조사를 권고합니다. 개인 단위 실제 데이터는 비식별 처리 후 사용합니다.
- 비용·운영 안정성: 배치 호출과 캐시로 API 비용을 통제하고, API 장애가 나도 캐시된 패널 결과로 시연할 수 있도록 설계합니다.

5. 성능 평가 지표
- 신뢰도 측정: 세그먼트별 Jensen-Shannon 거리, 컨셉 선호 순위 상관
- 결합 추정: 참값 대비 평균 절대 오차(MAE)와 불확실성 구간의 실제 포함률
- 비용 효과: 같은 오차를 달성하는 데 필요한 실제 표본 수(비교 방식 대비 절감률)
- 안정성: 반복 실행 간 결과 변동폭, 응답 형식 오류율, 응답 소요 시간

6. 본선 시연 구성
컨셉 입력 → AI 패널 조사 실행 → 세그먼트별 신뢰도 히트맵 → 실제 조사 표본 배정안 → 현장 데이터 기반 백테스트로 '실제만 / 고정 혼합 / 신뢰도 기반 혼합'의 오차 비교 그래프를 한 화면에서 보여줍니다.

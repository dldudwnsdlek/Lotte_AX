1. AI 모델 설계
(1) 순위 모델: 시점 t까지의 국가별 피처(수입 규모·성장률, 한국산 점유율 추이, 1인당 소득, 도시화율, 인구, 거리, 관심도 지표)로 t~t+3년 한국산 해당 품목 수입 증가를 예측하는 순위 학습 모델(LightGBM LambdaRank)과 해석이 쉬운 로지스틱 회귀를 비교·사용합니다.
(2) 공백 시장 탐지: 무역학의 중력모형(경제 규모·거리 등으로 교역량을 설명하는 모형)을 포아송 회귀(PPML)로 추정해 국가별 한국산 수입 기대치를 계산하고, 실제치가 기대치보다 크게 낮은 국가를 잠재 기회로 표시합니다.
(3) 가설 검증 엔진: 자연어 가설을 '지표 정의 → 피처 생성 → 백테스트 → 통계 판정' 절차로 변환합니다. 판정은 순위 상관과 모델 성능 기여로 하며, 여러 가설을 시험할 때 우연히 맞는 것을 고르지 않도록 다중 검정 보정(Benjamini-Hochberg)과 사전 고정된 검증 시점을 적용합니다.
(4) 민감도 분석: 가중치·모델·기간을 변형해 반복 계산하고, 국가별 TOP 3 잔존 확률을 산출합니다.

2. 활용 데이터
- 예선·사전 검증(공개 데이터): UN Comtrade(국가×품목×연도 수출입), 관세청·농식품수출정보(KATI, 국내 통계 교차 확인), World Bank WDI(소득·인구·도시화), CEPII Gravity DB(거리·공용어 등), Google Trends(관심도, 선택). 품목은 비스킷류·빙과 해당 HS 품목으로 정의합니다.
- 본선: 현장 데이터(국가·품목별 수출 실적 등)를 타깃과 피처로 연결합니다. 입력 스키마를 '국가·품목·연도(월)·금액/물량'으로 표준화해 타깃만 교체하면 동작하도록 설계합니다.

3. AI 에이전트 개발 방식
- 구조: LLM(OpenAI API)이 요청 해석, 분석 계획 수립, 도구 선택, 결과 설명을 담당하고, 계산은 검증된 Python 도구가 수행하는 함수 호출 기반 워크플로입니다. 도구는 데이터 조회기, 피처 생성기, 순위 모델, 중력모형, 가설 검증기, 민감도 분석기, 리포트 생성기로 구성합니다.
- 흐름: 요청 해석(품목·제외 국가·제약) → 데이터 조회·결측 처리 → 순위 모델과 공백 탐지 실행 → 가설 입력 시 검증 절차 수행 → 민감도 분석 → 근거 수치 자동 대조 → TOP 3 보고서와 후속 질문(what-if) 응답
- 가설 검증은 자유 코드 생성 대신 사전에 검증된 분석 도구 조합으로 수행해, LLM이 만든 코드의 오류 위험을 줄입니다.
- 화면: Streamlit으로 국가 순위, 근거 카드, 가설 검증 결과, 과거 시점 예측과 실제 결과를 나란히 비교하는 화면을 제공합니다.

4. 신뢰성·안정성 확보 방안
- 정량 검증: 2016·2018·2020년 시점 데이터만으로 예측해 이후 3년 실제 결과와 비교하는 롤링 백테스트로 평가합니다. 비교 기준은 ⓐ최근 성장률 외삽 ⓑ시장 규모순 ⓒ사람이 정한 가중 점수표입니다. 피처는 반드시 예측 시점까지의 데이터만 사용합니다.
- 노이즈 관리: 수출액이 매우 작은 국가는 소수 계약에 좌우되므로 금액 하한·로그 변환·다년 평균으로 처리합니다. 최근 연도 결측은 수입국 측 보고치(미러 데이터)로 보완하고 결측 여부를 표시합니다.
- 환각 방지: 보고서의 모든 수치는 데이터 조회 결과와 자동 대조하며, 불일치 시 재작성합니다. 출처가 없는 주장은 출력하지 않습니다.
- 범위 관리: 데이터로 판단할 수 없는 요인(현지 유통 파트너, 규제 세부사항)은 '추가 검토 필요'로 명시해 과신을 막습니다.
- 운영 안정성: 외부 API 장애에 대비해 데이터를 로컬 캐시로 관리하고, 동일 조건 재실행 시 같은 결과가 나오도록 난수 시드와 데이터 버전을 고정합니다.

5. 성능 평가 지표
- 순위 정확도: Hit@3·Hit@10, NDCG@10, Spearman 순위 상관
- 가설 검증: 실제 효과를 심어 둔 모의 가설과 효과 없는 가설의 판별 정확도
- 근거 신뢰성: 보고서 수치와 원 데이터의 일치율(목표 100%)
- 안정성: TOP 3 잔존 확률, 응답 소요 시간

6. 본선 시연 구성
현장 데이터 적재 → 조건 입력과 TOP 3 도출 → 담당자 가설 입력 후 백테스트 판정과 순위 갱신 → 과거 시점으로 돌려 예측한 결과와 실제 결과 비교 → 근거 카드가 포함된 보고서 출력 순서로 보여줍니다.

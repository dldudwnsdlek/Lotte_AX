■ 주요 프로젝트
1. 개인채무조정 상담 챗봇 (RAG, OpenAI API)
- LangChain + ChromaDB RAG 파이프라인 구현(배포 제외 전 과정), 공식 제도 자료로 Knowledge Base 직접 구축
- OpenAI Embeddings → ChromaDB 검색 → 대화 맥락 반영 질의 재구성 → GPT-4o-mini 답변, Streamlit 서비스화
- 근거 문서 기반으로 환각을 줄이는 LLM 서비스 설계 경험

2. EXAONE-4.0-1.2B 경량화 (LG Aimers 8기)
- llmcompressor 기반 GPTQ W4A16 양자화 파이프라인 구현, vLLM 추론 환경 구성
- MANTA·GSM8K-Ko·KMMLU-Redux 캘리브레이션 비율을 실험으로 비교해 최적 비율 도출

3. CNC 가공 불량 예측 + 다중 XAI 검증 (학술대회 발표, 제1저자)
- XGBoost + LightGBM + TabNet 스태킹 앙상블, F1 0.9546
- SHAP·KernelSHAP·TabNet Attention 교차 검증으로 핵심 불량 요인 도출 → 결과를 "왜 믿을 수 있는가"까지 검증

4. 지식 그래프 융합 LightGCN 음악 추천 (학술대회 은상, 제1저자)
- Melon 플레이리스트 14만 건 수집·전처리, 멤버-그룹 지식 그래프를 GCN으로 학습해 LightGCN에 순차 융합
- Recall@20·NDCG@20 기준 기존 LightGCN 대비 성능 향상 (PyTorch)

5. 금융 사기 거래 탐지 (금융결제원 가명 거래 데이터)
- 계좌 단위 파생 피처 45개 이상 설계, 사기 비율 0.03% 불균형을 SMOTE + 언더샘플링으로 해결
- 날짜 기준 분할로 미래 정보 누수 차단, CatBoost F1 0.968 (피처 단계별 0.925 → 0.934 → 0.968)

- 감정 기반 영화 추천: Amazon 리뷰 791만 건, DistilBERT 감정 분류 + NCF (Hit Rate@10 0.667)
